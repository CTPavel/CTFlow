# Политика конфиденциальности CTFlow

Дата вступления в силу: 2 августа 2026 года.

Эта политика описывает данные, используемые приложением CTFlow для предоставления VPN-доступа клиентам CTPavel.

## Какие данные обрабатываются

Для работы приложения могут использоваться:

- индивидуальная ссылка подписки и содержащийся в ней токен доступа;
- случайно созданный идентификатор устройства (HWID) и идентификатор установки;
- платформа, версия Windows, архитектура системы и имя/модель устройства;
- сведения о подписке: срок действия, использованный и доступный трафик;
- выбранные серверы, настройки приложения и правила маршрутизации;
- текущий публичный IP-адрес при запуске пользователем проверки IP;
- локальные технические журналы и сведения об ошибках.

При запросах к серверу подписки ему также технически доступен IP-адрес, с которого выполняется запрос, дата, время и стандартные сетевые метаданные.

## Для чего используются данные

Данные используются только для:

- проверки действительности подписки и лимита устройств;
- получения и обновления списка доступных серверов;
- отображения срока подписки и статистики трафика;
- установления VPN-соединения и применения выбранных правил маршрутизации;
- диагностики ошибок, предотвращения злоупотреблений и обеспечения безопасности сервиса.

CTFlow не содержит рекламных модулей и не продаёт персональные данные рекламным компаниям.

## Локальное хранение

Ссылка подписки, настройки, профили и журналы сохраняются на компьютере пользователя в каталоге `%APPDATA%\CTFlow`. Данные не следует публиковать или пересылать посторонним.

Журналы сбоев сохраняются локально и не отправляются автоматически. Пользователь передаёт их поддержке только по собственному решению.

После удаления CTFlow пользователь может вручную удалить каталог `%APPDATA%\CTFlow`, если сохранение настроек больше не требуется.

## Сетевые сервисы

В зависимости от используемой функции приложение может обращаться к:

- серверу подписки и VPN-серверам CTPavel;
- `api.2ip.io` и резервному сервису `api.ipify.org` для проверки публичного IP;
- `www.gstatic.com` для проверки доступности соединения;
- внешнему сайту проверки скорости, который открывается только по действию пользователя;
- Telegram при переходе по ссылке поддержки.

Для этих сервисов действуют их собственные политики конфиденциальности.

## Срок хранения и удаление

Серверные данные хранятся столько, сколько требуется для работы подписки, безопасности, учёта трафика и исполнения обязательных требований. Запросить уточнение или удаление данных можно через поддержку. Некоторые записи могут сохраняться дольше, если этого требует закон, предотвращение мошенничества или защита прав пользователей и сервиса.

## Защита данных

Применяются разумные технические меры защиты. Однако ни один способ хранения или передачи данных через интернет не обеспечивает абсолютной безопасности. Пользователь обязан хранить ссылку подписки в тайне и своевременно сообщать о её компрометации.

## Изменения политики

Политика может обновляться вместе с развитием CTFlow. Актуальная версия публикуется в этом репозитории.
