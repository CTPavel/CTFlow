# Политика конфиденциальности CTFlow

Дата вступления в силу: 16 августа 2026 года.

Эта политика относится к официальным приложениям CTFlow для Windows и Android.

## Кратко

CTFlow не содержит рекламных SDK и встроенной аналитики, не продаёт персональные данные и не отправляет диагностические журналы автоматически. Для работы подписки, VPN, проверки соединения и обновлений приложение обращается к указанным ниже сетевым сервисам.

## Какие данные обрабатываются

### Подписка и устройство

При добавлении или обновлении подписки могут обрабатываться:

- персональная ссылка CTFlow и возвращаемая сервером конфигурация;
- случайный идентификатор устройства (HWID) и идентификатор установки;
- платформа, версия операционной системы и архитектура;
- на Windows — имя компьютера;
- на Android — производитель и модель устройства;
- сведения о доступных серверах, сроке подписки и трафике.

Эти данные используются для авторизации устройства, выдачи конфигурации, ограничения доступа и работы клиентских функций.

### Сетевые данные

При подключении VPN сетевые узлы неизбежно получают технические сведения, необходимые для передачи трафика, включая исходный IP-адрес, время соединения и объём обмена. Порядок хранения серверных данных определяется правилами сервиса CTFlow и его инфраструктуры.

### Локальная диагностика

Приложения записывают локальный технический журнал: запуск и остановку компонентов, состояние VPN, смену сети, результаты проверок и тексты ошибок. Конфигурации, приватные ключи и персональная ссылка не должны записываться в журнал. Журнал передаётся поддержке только по инициативе пользователя.

### Приложения и процессы

- Windows может локально проверять запущенные процессы, чтобы обнаружить конфликтующие VPN-программы.
- Android показывает локальный список запускаемых приложений для настройки маршрутизации. Разрешение `QUERY_ALL_PACKAGES` не используется.

Эти списки не отправляются на сервер подписки.

## Где хранятся данные

### Windows

Пользовательские данные хранятся в `%APPDATA%\CTFlow`. Ссылка подписки защищается средствами Windows Data Protection API для текущей учётной записи.

### Android

Состояние приложения хранится в закрытом каталоге приложения, исключённом из резервного копирования. Чувствительные значения шифруются AES-256-GCM с ключом в Android Keystore. Очистка данных приложения или удаление приложения удаляет локальные настройки и журналы.

## Сетевые сервисы

В зависимости от выбранного действия и платформы CTFlow может обращаться к:

- `web.ctvpn.ru` — получение и обновление подписки; приложения принимают только HTTPS-ссылки этого домена;
- VPN-серверам из подписки — передача пользовательского трафика;
- `api.2ip.io` и `api.ipify.org` — определение внешнего IP;
- `www.gstatic.com` / `connectivitycheck.gstatic.com` и `1.1.1.1` — проверка фактической доступности сети и туннеля;
- `api.github.com`, `github.com` и `githubusercontent.com` — проверка и загрузка официальных обновлений;
- Speedtest.net или Яндекс Интернетометр — только при открытии проверки скорости пользователем;
- `t.me/CTPavel` — только при открытии ссылки поддержки.

Android во время активного VPN периодически проверяет работоспособность туннеля и повторяет проверку после смены сети. Это необходимо для автоматического восстановления соединения.

## Передача третьим лицам

CTFlow не продаёт пользовательские данные. Технические данные передаются только сервисам, необходимым для выбранной функции, и обрабатываются ими по их собственным правилам.

## Управление и удаление

Вы можете удалить подписку и настройки в приложении, очистить диагностический журнал, а также удалить приложение или его данные средствами операционной системы. Для вопросов по серверной учётной записи обратитесь в поддержку.

## Безопасность

Мы используем системные хранилища ключей, шифрование локальных секретов, HTTPS и проверку подлинности Android-обновлений. Ни одна система не обеспечивает абсолютную защиту; не публикуйте персональную ссылку подписки и диагностические данные.

## Изменения политики

Актуальная версия политики публикуется в этом репозитории. Дата вступления в силу обновляется при существенных изменениях.
