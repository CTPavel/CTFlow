# Безопасность CTFlow

Документ относится к официальным клиентам CTFlow для Windows и Android и файлам, опубликованным в [GitHub Releases](https://github.com/CTPavel/CTFlow/releases).

## Сообщить об уязвимости

Не публикуйте сведения об уязвимости в открытом issue до исправления. Отправьте сообщение в Telegram: [@CTPavel](https://t.me/CTPavel).

Укажите платформу, версию CTFlow и ОС, шаги воспроизведения, ожидаемый и фактический результат, возможное влияние и очищенный от секретов фрагмент журнала.

Не отправляйте персональную ссылку подписки, UUID, приватные ключи, полную конфигурацию сервера или чужие данные.

## Официальные файлы

- Windows-релизы используют теги `vX.Y.Z` и файл `CTFlow-Setup.exe`.
- Android-релизы используют теги `android-vX.Y.Z` и файл `CTFlow-Android-vX.Y.Z-arm64.apk`.
- Скачивайте файлы только из этого репозитория и сверяйте SHA-256, указанный GitHub.

Имя пакета Android: `ru.ctflow.android`.

SHA-256 официального сертификата подписи Android с версии 0.7.9:

`BA:BA:F8:E9:9A:0C:C6:A8:E9:5C:E1:EA:85:A5:B1:E9:4E:D2:7D:6F:D6:0E:92:E3:8F:11:21:F3:6F:7B:B9:04`

Для перехода с 0.7.8 и старше требуется переустановка из-за смены подписи. Версии с 0.7.9 используют текущий production-сертификат и обновляются поверх приложения.

Встроенное Android-обновление дополнительно проверяет размер, SHA-256, имя пакета, номер версии и сертификат подписи APK перед передачей файла системному установщику.

## Защита данных приложения

- Клиенты принимают ссылку подписки только с `https://web.ctflow.site/` и запрещают небезопасные варианты адреса.
- Windows защищает ссылку подписки через Data Protection API текущего пользователя.
- Android хранит чувствительные настройки в закрытом каталоге и шифрует их ключом из Android Keystore.
- Диагностические журналы хранятся локально и не отправляются автоматически.

Пользователь с административным/root-доступом или вредоносная программа с достаточными правами может обойти часть системной защиты. Защищайте устройство, устанавливайте обновления ОС и не передавайте ссылку подписки.

## Обновления

Клиенты проверяют GitHub Releases. Windows использует основной Windows-релиз, Android рассматривает только опубликованные теги `android-v*`. Устанавливайте обновления своевременно и не используйте APK или установщики из неофициальных источников.

## Срок ответа

Подтверждение получения сообщения и сроки исправления зависят от сложности и риска. Мы постараемся сообщить о результате после проверки и выпуска исправления.
