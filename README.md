# CTFlow

Официальные VPN-клиенты CTFlow для **Windows и Android**. Для подключения нужна персональная ссылка подписки CTFlow с доменом `web.ctflow.site`. Приложение загружает доступные серверы и управляет VPN-туннелем.

В этом репозитории находятся готовые приложения, документация и сведения о выпусках. Исходный код клиентов, серверные конфигурации и данные подписок не публикуются.

## Возможности

- импорт персональной подписки, её обновление и отображение срока действия и трафика;
- список серверов, проверка задержки, внешнего IP и доступности соединения;
- VLESS/REALITY, VMess, Trojan, Shadowsocks, SOCKS5 и Hysteria2;
- маршрутизация по приложениям и доменам, исключения из VPN;
- автоматическое восстановление после сбоев с проверкой фактической передачи трафика;
- локальный диагностический журнал и встроенная проверка обновлений через GitHub.

### DNS из подписки

В Windows **1.3.12** и Android **0.7.12** DNS-политика CTFlow автоматически применяется из полных Xray JSON-профилей подписки, включая отдельные серверы.

Текущая политика направляет DNS российских доменов к Яндексу напрямую, а остальных — к DNS CTFlow через VPN. Адреса резолверов вручную вводить не нужно. После обновления приложения обновите подписку и переподключитесь.

Явно выбранный локальный DNS в настройках Windows сохраняет приоритет. Собственный защищённый DNS браузера и исключённые из VPN приложения могут использовать свои настройки.

### Windows

- Xray и sing-box, системный TUN на базе Wintun;
- работа из области уведомлений и автозапуск;
- правила приложений и доменов, контроль конфликтующих VPN-процессов;
- повторные попытки восстановления и переключение между доступными серверами;
- защита профилей и ссылки подписки средствами Windows DPAPI.

### Android

- системный VPN через Android VpnService, Xray для основных протоколов и sing-box helper для Hysteria2;
- выбор приложений и доменных исключений, настройка темы и языка;
- восстановление при смене Wi-Fi/LTE, foreground-служба и виджет;
- защита чувствительных настроек через Android Keystore;
- проверка размера, SHA-256, имени пакета, версии и сертификата APK перед обновлением.

## Установка и начало работы

### Windows

1. Скачайте `CTFlow-Setup.exe` и завершите установку.
2. При первом запуске вставьте свою персональную ссылку вида `https://web.ctflow.site/ваш_ключ`.
3. Выберите сервер и нажмите «Подключиться».

Для установки и работы системного туннеля подтвердите запрос прав администратора. Сборка включает необходимые компоненты .NET; отдельно устанавливать SDK не требуется.

Для ZIP-версии распакуйте архив целиком и запустите `CTFlow.Windows.exe`.

### Android

1. Скачайте APK и разрешите его установку для используемого браузера или файлового менеджера.
2. Установите CTFlow и добавьте персональную ссылку с `https://web.ctflow.site/`.
3. Подтвердите системный запрос Android на создание VPN-подключения.
4. Выберите сервер и подключитесь.

**Обновление с 0.7.9 и новее устанавливается поверх приложения.** Версии 0.7.8 и старше используют прежнюю подпись: перед переходом сохраните ссылку подписки, удалите старое приложение и установите актуальный APK. Локальные настройки при удалении приложения теряются.

## Обновления

Приложения проверяют новые версии при запуске и вручную из настроек. Подтверждение установки выполняется средствами Windows или Android.

После обновления до выпуска с новой DNS-политикой обновите подписку и переподключите VPN — изменять каждый сервер вручную не требуется.

## Проверка подлинности

Скачивайте файлы из [этого репозитория](https://github.com/CTPavel/CTFlow/releases). Для выпусков приложены файлы контрольных сумм; GitHub также показывает SHA-256 каждого файла.

- Имя пакета Android: `ru.ctflow.android`.
- SHA-256 сертификата Android **с версии 0.7.9**:

`BA:BA:F8:E9:9A:0C:C6:A8:E9:5C:E1:EA:85:A5:B1:E9:4E:D2:7D:6F:D6:0E:92:E3:8F:11:21:F3:6F:7B:B9:04`

Не передавайте другим людям персональную ссылку подписки, UUID и приватные ключи.

## Диагностика и поддержка

- Windows: журнал и пользовательские данные находятся в `%APPDATA%\CTFlow`.
- Android: откройте настройки и раздел диагностики; журнал можно просмотреть, скопировать или очистить.
- После изменения подписки сначала обновите её и переподключитесь. При сбое проверьте другой сервер и сохраните журнал сразу после повторения ошибки.

Журналы не отправляются автоматически. Перед передачей в поддержку удалите персональные ссылки, UUID и ключи.
