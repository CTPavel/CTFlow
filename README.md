# CTFlow

Официальный VPN-клиент для Windows, предназначенный для клиентов сервиса CTPavel.

CTFlow получает доступ к серверам по индивидуальной ссылке подписки. Репозиторий содержит только пользовательскую документацию и файлы публичных выпусков. Исходный код, серверные конфигурации и данные подписок здесь не публикуются.

## Возможности

- работа через Xray и sing-box;
- поддержка VLESS с транспортами gRPC, TCP и XHTTP, включая REALITY;
- системный TUN-режим для трафика Windows;
- исключения и отдельные правила для выбранных приложений;
- последовательная проверка задержки серверов;
- проверка IP-адреса до и после подключения;
- автоматическое обновление списка серверов и данных подписки;
- автоматический выбор следующего доступного сервера при неудачном подключении;
- предупреждение о конфликтующих VPN, TUN-приложениях, Happ, GoodbyeDPI и Zapret;
- сворачивание в системный трей и защита от запуска нескольких экземпляров;
- контроль использования оперативной памяти VPN-ядрами.

## Системные требования

- Windows 10 версии 1809 или новее либо Windows 11;
- 64-разрядная система;
- права администратора для создания TUN-интерфейса и изменения маршрутов;
- активная подписка CTPavel.

## Установка

1. Откройте раздел [Releases](https://github.com/CTPavel/CTFlow/releases).
2. Скачайте последний файл `CTFlow-Setup.exe`.
3. Запустите установщик и подтвердите запрос контроля учётных записей Windows.
4. Откройте CTFlow и вставьте индивидуальную ссылку доступа, если она ещё не сохранена.
5. Выберите сервер и нажмите «Подключиться».

Используйте установщики только из этого репозитория или полученные напрямую от [@CTPavel](https://t.me/CTPavel).

## Важные рекомендации

- Не передавайте другим людям ссылку подписки, HWID и диагностические логи.
- Перед подключением отключайте другие VPN, GoodbyeDPI, Zapret и программы, создающие собственный TUN-адаптер.
- Если CTFlow обнаружит возможный конфликт, безопаснее отменить подключение, закрыть указанную программу и повторить попытку.
- Для применения изменений в исключениях приложений переподключитесь к серверу.

## Диагностика

При возникновении ошибки:

1. отключите другие VPN и средства обхода DPI;
2. перезапустите CTFlow с правами администратора;
3. обновите подписку;
4. попробуйте другой сервер;
5. приложите к обращению описание ошибки и логи без ссылки подписки.

Локальные данные CTFlow находятся в `%APPDATA%\CTFlow`. Не публикуйте содержимое этой папки в открытых обращениях.
