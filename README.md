# CTFlow

Официальные клиенты CTFlow для Windows и Android. Приложения работают с персональной ссылкой подписки, полученной на [web.ctvpn.ru](https://web.ctvpn.ru/), загружают доступные серверы и создают защищённый VPN-туннель.

> В этом репозитории публикуются установочные файлы, APK, документация и сведения о релизах. Исходный код клиентов, серверные конфигурации и данные подписок здесь не размещаются.

## Скачать

Используйте только раздел [Releases](https://github.com/CTPavel/CTFlow/releases).

| Платформа | Требования | Тег релиза | Файл |
|---|---|---|---|
| Windows | Windows 10 версии 1809 или новее / Windows 11, x64 | `vX.Y.Z` | `CTFlow-Setup.exe` |
| Android | Android 8.0 или новее, ARM64 | `android-vX.Y.Z` | `CTFlow-Android-vX.Y.Z-arm64.apk` |

Релизы для Windows и Android публикуются независимо. Проверяйте название платформы и файла перед установкой.

## Возможности

- импорт персональной ссылки CTFlow и автоматическое обновление подписки;
- список серверов, измерение задержки и быстрый выбор подключения;
- отображение срока подписки и использованного трафика;
- проверка внешнего IP и переход к проверке скорости;
- маршрутизация по приложениям и доменам;
- локальная диагностика без автоматической отправки журналов;
- встроенная проверка новых версий через GitHub Releases.

### Windows

- подключения через Xray и sing-box;
- системный TUN на базе Wintun;
- правила для приложений и доменов, список исключений и контроль конфликтующих VPN-процессов;
- автозапуск, работа из области уведомлений и восстановление зависшего туннеля.

### Android

- Xray-туннель через системный Android VpnService;
- выбор приложений, доменных исключений, темы и языка интерфейса;
- контроль фактической передачи трафика, автоматическое восстановление и переподключение при смене Wi-Fi/LTE;
- защищённое локальное хранение настроек;
- обновление APK с проверкой размера, SHA-256, имени пакета, версии и сертификата подписи.

## Установка

### Windows

1. Скачайте `CTFlow-Setup.exe` из Windows-релиза.
2. Запустите установщик и завершите установку.
3. При первом запуске вставьте персональную ссылку с `https://web.ctvpn.ru/`.
4. Выберите сервер и нажмите «Подключиться».

Для установки драйвера и управления туннелем Windows может запросить права администратора.

### Android

1. Скачайте APK из Android-релиза на телефон.
2. Разрешите установку приложений из этого источника только для используемого браузера или файлового менеджера.
3. Установите APK и при первом запуске вставьте персональную ссылку с `https://web.ctvpn.ru/`.
4. Подтвердите стандартный системный запрос на создание VPN-подключения.

Android и оболочки производителей могут показывать дополнительные предупреждения для APK, установленных не из магазина. Проверяйте, что файл загружен именно из этого репозитория.

## Проверка подлинности

- GitHub показывает SHA-256 для файлов релиза; сравните его с хешем скачанного файла.
- Имя пакета Android: `ru.ctflow.android`.
- SHA-256 сертификата подписи Android: `3F:75:79:99:0D:2C:88:8F:87:B0:C0:C5:52:0F:58:B1:52:9E:C3:B9:31:F0:2C:98:3C:BC:FF:B1:D0:B6:A7:84`.
- Не передавайте другим людям ссылку подписки, HWID и полный диагностический журнал.

## Диагностика

- Windows: журнал и пользовательские данные находятся в `%APPDATA%\CTFlow`.
- Android: журнал доступен внутри приложения в разделе настроек; его можно просмотреть, скопировать или очистить.

Перед обращением в поддержку удалите из снимков экрана и журналов персональную ссылку, UUID, ключи и другие секреты.
